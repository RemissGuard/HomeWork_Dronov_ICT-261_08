## **1. Алгоритм и блок-схема**
Алгоритм
1. Начало
2. Объявить переменные:
int n;
double x, y;
3. Предложить пользователю ввести значение x:
puts("Введите значение x");
4. Принять введенное значение переменной x:
scanf("%lf", &x);
5. Задать формулу для нахождения начального значения переменной y:
y = sin(x);
6. Вывести на экран начальное значение переменной y:
printf("sin(x)=%lf\n", y);
7. Предложить пользователю ввести значение n:
puts("Введите значение n");
8. Принять введенное значение переменной n:
scanf("%d", &n);
9. Используя цикл for прибавлять к переменной y ее предыдущее значение, пока i<=n:
for (int i = 1; i <= n; i++)y += sin(y);
10. Вывести конечный результат:
printf("%lf", y);
11. Конец

## **2. Реализация программы**
```
#define _CRT_SECURE_NO_WARNINGS
#include<stdio.h>
#include<locale.h>
#include<math.h>

int main()
{
    setlocale(LC_CTYPE, "RUS");
    int n;
    double x, y;
    puts("Введите значение x");
    scanf("%lf", &x);
    y = sin(x);
    printf("sin(x)=%lf\n", y);
    puts("Введите значение n");
    scanf("%d", &n);
    for (int i = 1; i <= n; i++)y += sin(y);// контрольный пример при x=1.57 и n=0 y=1
    printf("%lf", y);
}
```
